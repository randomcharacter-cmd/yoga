# Krishna Yoga - Professional Yoga Studio Website

A modern, responsive website for Krishna Yoga studio located in Navi Mumbai, India.

## Features

✨ **Modern & Professional Design**
- Clean, contemporary aesthetic with smooth animations
- Gradient color schemes and professional imagery
- Intuitive navigation and user-friendly interface

⚡ **Performance Optimized**
- Inline CSS for critical rendering path
- Optimized images with lazy loading
- Minimal JavaScript for fast load times
- Works perfectly on slow connections and old hardware

📱 **Fully Responsive**
- Mobile-first design approach
- Seamless experience across all devices
- Touch-friendly navigation
- Optimized for tablets and desktops

🎯 **Complete Sections**
- Hero section with call-to-action
- About the studio
- Class offerings (Hatha, Vinyasa, Ashtanga, Restorative, Pranayama, Meditation)
- Weekly class schedule
- Instructor profiles
- Contact information with studio details

## Technology Stack

- **HTML5** - Semantic markup
- **CSS3** - Modern styling with Flexbox and Grid
- **Vanilla JavaScript** - Minimal, efficient interactions
- **Unsplash Images** - High-quality, optimized yoga photography

## Performance Highlights

- Inline critical CSS for instant rendering
- Lazy-loaded images
- No external dependencies
- Lightweight codebase (~25KB HTML + CSS)
- Mobile-optimized with responsive breakpoints

## Browser Support

Works on all modern browsers:
- Chrome, Firefox, Safari, Edge (latest versions)
- Mobile browsers (iOS Safari, Chrome Mobile)
- Compatible with older browsers with graceful degradation

## Local Development

Simply open `index.html` in any web browser. No build process or dependencies required.
